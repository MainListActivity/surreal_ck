# P0 · 批量签发与一次性 CSV（B1）

- [ ] admin 可就本案名册单次签发至多 500 条；校验全部名册 ID、重复项和原生记录配额。
- [ ] 整个批次在一个事务中换发并保留最小审计；余额不足、并发冲突或部分失败均不遗留改动。
- [ ] 管理人从名册多选并下载名称、识别码、链接；明文只用于当次下载，不入库、不进日志或缓存；防 CSV 公式注入。
- [ ] 管理人可不换发而独立作废单条链接；最小审计记录对象 ID，不带令牌或正文。
- [ ] 在真实 fork 验证配额拒绝及回滚，在页面验证批量下载与旧链接作废。
