# 02 · 协同 APP 壳层与产品文案改版（v2 阶段一）

**目标**：按 `docs/design/collaboration-client-v2/README.md` 落第 1–2 步，彻底消除当前原生客户端的“工程验收工具感”，重构导航壳层与登录入口。

## 范围

1. **文案与空状态产品化**：替换 `native-client/src/first_screen.rs` 等处的工程说明性文案（如“不会生成示例联系人”“不会模拟登录”“尚未接入企业会话”），改为自然、诚实的产品文案，不伪造未实现能力（保持“已送出”不冒充“已读”）。
2. **四模块一层导航壳层**：重构为左侧 72px 图标栏（消息、会议、通讯录、设置），顶部工作区切换浮层，底部设置与头像；移除浅色页面顶部重复灰条与常驻首屏的“断开并停止媒体”按钮。
3. **启动首屏登录流**：将原本藏在“成员”页的 OIDC/PKCE 登录与工作区选择前置到启动第一屏（登录 → 等待系统浏览器回调/可重开或取消 → 选择工作区）。
4. **状态集中与开发者工具降级**：网络异常（重连中/离线）和媒体占用（红色麦克风/摄像头胶囊，支持单停/全停）统一收口到标题栏右侧；P2P 连接码、STUN/TURN、诊断面板下沉至「设置 → 开发者诊断」折叠入口。

## 非目标

- 不改底层 WebRTC 媒体协议、不新增后端信令接口、不实现 v2 尚未有后端支撑的在线状态/已读回执（无数据不显示，不用假值占位）。

## 独立验收标准

- [ ] 启动未登录客户端直接进入「登录与选择工作区」引导屏；完成 OIDC 回调后正确展示当前工作区与四模块导航。
- [ ] 全应用界面扫描（含空会话、未开会、离线态）不再出现工程测试/说明性文案及常驻首屏的“断开并停止媒体”按钮。
- [ ] 会议中标题栏右侧显示红色媒体占用胶囊，点击可单独关闭设备或一键停止全部媒体；断网时显示重连/离线胶囊，正常态不占位。
- [ ] 开发者诊断默认折叠在设置底部，不影响普通设置的清晰分层；保留既有指纹核对、更新门禁与隐私告警行为不回归。
- [ ] `native-client` 单元测试、headless UI 测试与 `cargo check`/`clippy` 在目标平台全部通过，并附关键页面真实截图或录屏证据。

**依赖**：无（基于 `docs/design/collaboration-client-v2/README.md`，可立即开工）。  
**验证方式**：Rust 单元测试 + headless UI 回归 + macOS 桌面构建实测截图。

- `main` 已合入首屏登录、工作区选择、四模块导航、标题栏状态和设置中的诊断入口。以 Rust 1.99.1 在 Apple Silicon 运行原生客户端单元与无界面交互测试，并通过同配置的 `cargo check`、`clippy`。[PR #319](https://github.com/MainListActivity/surreal_ck/pull/319) · [本轮命令与回执](12-meeting-e2e-and-pilot-acceptance.md#本地验收回执)
- 上述五项按原验收口径保留未勾选。需在同版桌面候选包用真实账号回调，实扫空会话、离线、媒体单停与全停、诊断、指纹和更新门禁，并留关键页面脱敏截图。Windows 等其他目标平台的检查也需补证。
