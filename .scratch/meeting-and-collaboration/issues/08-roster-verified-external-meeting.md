# 08 · 名册核验型外部正式会议（支撑破产债权人会议）

**目标**：建立关联工作簿外部主体名册的“受控外部正式会议”机制（通用平台抽象，破产债权人会议字段与话术由 `workbook_template` 模板包提供），实现批量发邀请、个人免注册实名核验入会、单活防转发与即时吊销。

## 范围

1. **会议与工作簿名册绑定**：在工作簿内创建正式外部会议（标题、计划时间、关联外部主体数据表、可选准入模式：名册直通 / 名册+等候室二次确认）；新增增量 `.surql` 迁移，不出现法律硬编码表名或字段名。
2. **复用外部门户安全模型批量签发**：支持 admin 按名册批量签发个人专属参会链接与访问码（单次上限 500 条，事前预检 workspace 原生记录配额，超额整批拒绝）；明文仅用于一次性导出 CSV（防公式注入），数据库只存哈希，支持对单个主体独立补发/吊销（旧链接即刻作废）。
3. **免下载免注册实名入会**：外部主体在浏览器（桌面/手机）打开专属链接，输入访问码（及可选名册校对字段，如主体名称末位/识别码）后通过受控服务端会话进入会议；参会展示名严格取自名册记录，不允许参会人自行伪造他人姓名。
4. **防转发单活互踢**：同一名册主体的个人令牌在有效期内仅允许 1 个活跃会话（新设备核验通过后自动踢下旧会话并记录审计，或按会议配置拒绝并发登录），防止链接被转发给无关人员旁听保密会议。
5. **最小审计**：批量签发、单人吊销、实名核验成功/失败、互踢、主持人踢出均写最小审计（操作者、对象 ID、时间），不落盘令牌明文与访问码。

## 非目标

- 不为名册外部主体创建工作区 `user` 账号，不下发 SurrealDB 凭证；会中秩序强控与表决回写分别在 `09`、`10` 实现。

## 独立验收标准

- [ ] 平台代码、新增 `.surql` schema、API 路径与提示词中零法律/破产硬编码词汇；破产债权人会议预设通过模板包配置注入并通过模板集成测试。
- [ ] admin 批量签发遵循原生配额预检，余额不足或并发冲突时整批回滚不留残余；导出 CSV 具备防公式注入转义，库内仅存令牌哈希。
- [ ] 外部主体在无账号、无客户端的手机/桌面浏览器中凭专属链接 + 访问码实名入会，展示名锁定为名册真实名称；错误链接/过期/已吊销/错访问码返回不可区分的统一错误并触发限速。
- [ ] 同一令牌在第二个浏览器登录时触发单活互踢（旧端在 SFU 与信令双侧断开并提示被顶下线）；admin 吊销某主体令牌后，该主体立刻被踢出且无法重入。
- [ ] 真实公司 SurrealDB fork 集成测试（覆盖批量事务回滚、配额拦截、互踢、吊销、零 DB 越权）+ 真实浏览器实测全部通过。

**依赖**：`01`、`07`（复用 `external-collaborator-portal` 令牌安全契约）。  
**验证方式**：真实 fork 集成测试 + 模板包测试 + 浏览器多端互踢/吊销实测。
