# 05 · Web 浏览器会议端与原生协同 APP 互通

**目标**：在 `web/`（`l.maplayer.top`）构建免下载浏览器会议界面，使工作区内部成员在未安装桌面客户端的电脑或手机上也能发起/加入日常办公会议，并与 macOS/Windows/Android 原生协同 APP 音视频、共享与聊天完全互通。

## 范围

1. **Web 会议入口与会前检查**：在工作区导航增加会议入口（立即开会 / 输入会议号加入 / 当前进行中会议）；入会前提供浏览器设备权限检测、麦克风音量条、摄像头预览与纯音频入会选项。
2. **跨端信令与媒体互通**：Web 端复用 `01` 锁定的信令与 `04` 的托管短期 ICE 凭据，接入原生会议房间，保证 **Web ↔ 原生 APP** 与 **Web ↔ Web** 的音频、视频、屏幕共享（桌面浏览器）、会中文字消息、成员进出与主持人结束会议状态完全同步。
3. **移动端与内置浏览器兼容**：适配手机 Safari / Chrome 竖屏布局；检测到微信/钉钉等不支持或受限 WebRTC 的内置浏览器时，展示清晰的中文「点击右上角在系统浏览器打开」引导页，不呈现白屏或报错栈。
4. **隐私与设备回收**：离开会议、被主持人结束或关闭标签页时，立即 `track.stop()` 释放全部摄像头/麦克风/共享流并发送离会信令，浏览器红点立刻消失。

## 非目标

- 本任务仅覆盖已登录工作区内部成员；外部免注册访客与名册核验入口由 `06` 和 `08` 承担。
- Web 端不实现原生桌面端独占的本地大文件 P2P 落盘协议（会中文件分享走工作区受控附件或明确提示范围）。

## 独立验收标准

- [ ] 内部成员在 Chrome / Safari 浏览器打开 `l.maplayer.top` 可创建会议并生成会议号，原生协同 APP 输入该会议号可成功入会，反之亦然。
- [ ] Web 端与原生端之间双向音频、视频、屏幕共享与会中文本消息互通正常，成员列表与离开/结束状态在 3 秒内同步。
- [ ] 拒绝浏览器摄像头权限时可降级为纯音频入会；离开或主持人结束会议后浏览器媒体占用指示灯立即熄灭。
- [x] 模拟微信内置浏览器 UA 打开会议链接时展示清晰的外部浏览器打开引导，不触发未捕获异常（浏览器能力单测及本地 Chrome 页面）。
- [ ] 前端组件/状态机测试 + 真实浏览器与原生端联测记录通过并留档。

**依赖**：`01`、`04`。  
**验证方式**：前端单测 + 桌面 Chrome/Safari 与 macOS 原生 APP 真实联测 + 手机浏览器实测。
