# 13 · 会议受控录制、举手表决账本与司法防篡改存证包

**目标**：满足破产债权人会议等正式外部会议对**参会身份、视频内容、音频内容、举手发言与表决结果**四类完整证据的合规留存与防篡改需求，产出可一键下载、可独立核验哈希的加密《会议存证包》，同时保证录制过程不拖垮生产业务库主机。

## 范围

1. **存证模式开关与入场知情确认**：
   - 日常办公会议默认关闭录制（主持人可手动开启）；正式外部会议默认开启「全程存证模式」。
   - 存证模式下，所有内部与外部参会人入场前必须展示醒目中文告知并勾选知情确认（记录知情确认时间戳与主体 ID，未确认禁止进入会场），会中全端常驻红色「存证录制中」指示条。
2. **四类证据的服务端权威采集**：
   - **谁当时参会**：聚合核验记录（名册令牌哈希 ID / OIDC 主体、实名映射、脱敏 IP/UA）与 SFU 服务端 `join/reconnect/leave/kicked/superseded` 精确 UTC 时间戳流水，不信任客户端本地时钟。
   - **视频与音频内容**：在私有 SFU 侧采用**轻量轨道直录（Track Egress）**直接采集共享流、主讲/发言视频轨与混音/分发言人音轨并实时加密写入隔离存储（会中极低 CPU 占用，不与生产 SurrealDB 争抢转码资源）；会议结束后由独立/离线合成作业生成带**服务端 UTC 水印时间戳与会议号**的标准存档 MP4 及分轨音频。
   - **举手发言与表决内容**：联动 `10` 的只追加（append-only，`PERMISSIONS` 禁止 `UPDATE/DELETE`）事件表，固化每次举手、放麦/收麦时间线、表决议题版本哈希、个人投票与异议提交记录及汇总快照，与音视频 UTC 时间轴精确对齐。
3. **独立私有加密存储与权限隔离**：
   - 音视频与存证包采用工作区级信封加密存放在私有对象存储（如独立 R2 桶，键前缀绑定 `workspace_id + meeting_id`），**严禁公网直链访问**。
   - 仅工作区管理员可经 Bun origin 鉴权获取短时签名下载链接；记录每次下载审计；普通成员、外部访客与跨工作区调用均返回 `403`。
   - 明确与工作区存储容量/归档保留周期的衔接，到期前提醒管理人离线备份，不静默删除未归档证据。
4. **不可变《会议存证清单》与根哈希封存（预留 TSA 司法时间戳）**：
   - 归档完成后自动生成不可变《会议存证清单（Evidence Manifest）》JSON + 可读摘要 PDF：列出会议元数据、签到名册、举手发言记录、表决明细、所有音视频与附件的精确字节数和 **SHA-256 哈希**。
   - 对整份清单计算 32 字节 **Root SHA-256 根哈希**写入工作区只读归档表（`PERMISSIONS` 禁改禁删），并打包为可离线校验的完整存证包（附离线校验说明）。
   - 定义可插拔的**外部可信时间戳（TSA）/ 司法存证适配器接口**：仅提交 32 字节 Root SHA-256 摘要（绝不外传案件名单、文本或音视频原件），保存权威时间证明回执；首期提供接口契约与本地测试替身，真实商用 TSA 供应商凭据按老板决策后接入。

## 非目标

- 不在跑生产 SurrealDB 的 VPS 主核上运行高 CPU 无头浏览器实时合成录像；不在首期强制绑定特定商用 TSA 供应商账号；平台代码与 schema 中不出现法律/破产硬编码词汇。

## 独立验收标准

- [ ] 存证模式会议未勾选知情确认无法进入会场；进入后原生 APP、桌面与手机浏览器均常驻红色录制标识；日常会议未开启录制时绝不产生音视频文件落盘。
- [ ] 真实跑完一场含「多人签到 + 断线重连 + 屏幕共享 + 举手点名发言 + 发起表决与异议 + 结束会议」的存证会议，成功产出带服务端 UTC 水印的 MP4、清晰音频（及分发言人音轨）、签到 CSV/PDF、举手发言时间线与表决汇总，音画同步且时间轴与数据库事件误差 ≤ 2 秒。
- [x] 《会议存证清单》覆盖全部产物 SHA-256 与 32 字节 Root SHA-256；人为篡改任意 1 字节视频或表决明细后，离线校验脚本报哈希不匹配；完整 schema 下工作区只读归档记录与只追加事件表拒绝任何角色 `UPDATE/DELETE`（真实 fork 负例验证）。
- [ ] 录制与存证包在对象存储中为加密态且无公网直链；非本工作区管理员（含外部参会人、同工作区普通成员、其他工作区管理员）请求下载一律返回 `403`。
- [ ] 30+ 参会人并发下开启轻量轨道直录（Track Egress），记录主机 CPU/内存/磁盘 IO 水线，证明不会引起同期 Hono API 或 SurrealDB 延迟劣化。
- [x] TSA 摘要存证适配器契约测试通过，断言出站载荷仅含 32 字节根哈希与最小请求元数据，零业务正文或个人身份信息外发（本地测试替身）。

**依赖**：`01`、`07`、`09`、`10`。  
**验证方式**：真实公司 SurrealDB fork 权限/防篡改负例测试 + SFU 轨道直录与异步合成端到端实测 + 存证包离线哈希校验 + 压测资源基线记录。

**防篡改验收边界（M-01 ADR）**：真实 fork 验证完整 schema 下包括 Owner/root 的直接 `UPDATE/DELETE` 被拒；普通角色不能移除守卫。Owner/root 有权修改工作区 schema，因此另验通过 DDL 移除守卫后篡改工作区投影会被独立核验发现。权威账本与根锚点位于独立存证域，不从工作区投影或存证包自身取得可信根。
