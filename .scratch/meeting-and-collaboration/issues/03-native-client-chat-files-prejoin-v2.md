# 03 · 协同 APP 消息分组、文件卡片与会前检查（v2 阶段二）

**目标**：按 `docs/design/collaboration-client-v2/README.md` 落第 3–5 步，补齐律所日常办公必需的聊天交互、显式文件传输卡片、会议浅色首页、会前音视频检测与防递归共享体验。

## 范围

1. **消息与文件体验**：同一发送者 1 分钟内连续消息合并分组（头像/姓名/时间不重复）；发送中/已送出/失败红色虚线框与重试；按会话保存草稿；接收文件卡片明确展示「拒绝 / 选择位置并接收」，发送前待确认与取消，延续 SHA256 与原子落盘语义。
2. **会议首页与会前检查**：会议模块默认浅色首页（立即开会 / 输入会议号 / 进行中 / 最近结束）；入会前统一经过「会前检查」（本机画面预览、麦克风实时音量条、扬声器测试、设备选择）；摄像头/麦克风未授权时给出清晰提示与「打开系统设置」，允许仅语音加入且不循环弹窗。
3. **舞台共享与迷你浮窗**：共享选择器区分窗口与整个屏幕，未选源时禁用「开始共享」，选整个屏幕提示风险；自己共享时顶部常驻金色共享条，舞台切换为安全提示画面避免无限画面嵌套；支持「返回消息」将进行中会议最小化为右下角迷你条。
4. **通讯录与快捷键**：在现有只读成员目录上增加搜索与资料卡（一键发消息/发起会议）；支持 `⌘K`/`Ctrl+K` 快速跳转、Esc 关闭弹窗、系统减少动态效果适配。

## 非目标

- 不虚构未落地的后端字段（如未读数/已读回执/跨组织通讯录）；系统声音共享按平台实际能力条件显隐。

## 独立验收标准

- [ ] 连续多条消息正确合并分组，断网发送失败显示重试按钮且不丢草稿；文件显式接收、拒绝、进度与取消流程在桌面端真实跑通。
- [ ] 点击「立即开会」或「加入会议」必经会前检查；拒绝摄像头权限后仍可正常仅音频入会且不反复弹权限窗。
- [ ] 发起屏幕共享时未选源无法开始；共享本窗口/全屏期间不出现画面无限递归嵌套，停止共享后立即释放采集并消除红标。
- [ ] 会议中点击「返回消息」后音频/共享保持不断，右下角迷你条可一键静音、切回舞台或离开。
- [ ] 新增 headless 组件与模型测试覆盖全部状态转换，`native-client` 测试集全绿。
