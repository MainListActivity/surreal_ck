# 06 · 日常办公外部访客免下载免注册入会与等候室

**目标**：解决律所日常办公中临时邀请外部客户、顾问或合作方开会的痛点——外部人员**无需下载客户端、无需注册账号**，通过浏览器打开受控链接、经主持人等候室放行即可安全参会，且严格隔离工作区数据。

## 范围

1. **受控访客链接签发**：主持人创建或进行日常会议时，可显式开启「允许外部访客」并生成独立访客链接（可设可选 6 位访问码与默认到期时间，随时一键重置或关闭）；默认关闭，遵循 fail-closed。
2. **免注册访客入会页**：外部人员在独立公开路由打开链接（不走 OIDC 登录），输入访问码（如已设）和展示名称，完成设备检测后进入**等候室**；无效链接、已过期、已关闭或错误访问码返回统一错误提示，防枚举并按 IP + 链接限速。
3. **主持人等候室与秩序控制**：主持人端实时收到等候室提醒，可「放行」「拒绝」或「移出并禁止本次重入」；支持一键「锁定会议」阻止任何新访客加入。
4. **严格安全与数据边界**：访客会话由后端受控签发短期会议作用域 token（仅限该场会议的信令与媒体），**不创建工作区 `user` 记录、不下发 SurrealDB 凭证、不可见工作区成员目录/历史消息/任何业务表**；会议结束、被移出或链接撤销后，访客会话在下一请求及媒体侧立即失效。

## 非目标

- 不提供匿名直入（未放行前严禁下发媒体流或会议聊天内容）；不做需要实名名册核验和工作簿表决回写的大型正式会议（见 `08`–`10`）。

## 独立验收标准

- [ ] 会议默认不开放外部访客；主持人开启后生成的访客链接在无账号、无客户端的隐私浏览器中可打开并进入等候室。
- [ ] 访客在等候室等待期间，服务端绝不下发房间成员信息、会中聊天、SDP 或 ICE/SFU 媒体凭据（自动化负例测试覆盖）。
- [ ] 主持人放行后，访客在浏览器中与原生 APP/Web 内部成员双向音视频和屏幕共享正常；主持人点击「移出并禁重入」或「结束全体会议」后，访客端 3 秒内断流且旧会话 cookie/token 重放返回 `401/403`。
- [ ] 访客尝试调用任何工作区 API 或使用访客 token 连接 SurrealDB 均被拒绝；无效/过期/错码响应不可区分，触发限速返回 `429`。
- [ ] 后端权限与状态机集成测试（含真实 fork）+ 隐私浏览器端到端实测通过。

**依赖**：`01`、`04`、`05`。  
**验证方式**：真实 fork 集成测试（正反例）+ 隐私浏览器（无登录态）与原生 APP 跨端实测。
