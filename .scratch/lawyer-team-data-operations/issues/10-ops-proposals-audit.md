# 10 — 运营建议审阅与行动记录

**What to build:** agent 提交包含依据及预期结果的运营建议，人工在独立页面审阅或接管，双方读取同一行动状态与结果。

**Blocked by:** 09 — 运营机会与跟进队列

**Status:** done

- [x] 建议关联跟进事项、摘要版本、明确动作及预期结果；页面和 MCP 均可提交、读取及处理具备权限的建议。
- [x] 需要审阅的建议在审阅前不执行，审阅绑定具体版本和动作；前提变化后旧批准失效，批准不扩大 capability。
- [x] 仅接入当前具备实现和授权的内部跟进动作；客户写入、外部消息或商业权益变更不得因批准文字被执行。
- [x] 审计记录触发原因、授权主体、agent 标识、输入摘要、幂等键、状态及工具结果；不记录 token、案件正文或隐藏推理。
- [x] 人工可接管事项并使旧认领失效；执行成功依据来自实际动作结果，不以模型自述标记成功。
- [x] 测试重复审批、过期前提、越权审批、执行失败与接管竞争，页面和 MCP 返回等价结果。
