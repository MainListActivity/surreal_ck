# 02 — 导入批次安全撤销

**What to build:** 用户能够预览并撤销误导入的新增记录，系统保护后续编辑和批次外引用，保留可解释的撤销结果。

**Blocked by:** 01 — 导入批次持久化与安全重试

**Status:** ready-for-agent

- [ ] 批次结果页提供撤销预检，列出拟删除记录数量和阻碍；仅处理本批次新建记录。
- [ ] 记录被后续修改、被批次外引用或调用者无删除权限时整体拒绝，不部分删除。
- [ ] 用户确认后在同一事务内重新验证预检前提，删除符合条件的记录并提交撤销回执；并发变化返回冲突。
- [ ] 保留批次及审计，不隐式删除数据表、字段或工作簿；重复撤销返回既有结果。
- [ ] 界面显示预检、冲突和已撤销状态；真实数据库测试覆盖正常撤销、并发编辑、外部引用及权限拒绝。

## 共同约束

- 父规格为“律师团队数据完善与运营闭环”；本票不改变其范围与身份边界。
- 复用现有模块、领域词汇和 ADR；必要的局部预重构先保持现有行为测试通过，再增加本票能力。
- 按实际涉及内容加载仓库规定的技能；业务数据使用调用者会话，权限落在数据库，不新增业务 CRUD/LIVE 后端代理。
- 交付包含所需持久化、授权、界面或工具入口与行为测试，不以单一层实现作为完成。
