# 04 — 模板规则与跨记录检查

**What to build:** 管理员为模板选择检查规则和参数，律师在体检中看到疑似重复、引用缺失及字段一致性问题，并能追溯规则版本。

**Blocked by:** 03 — 全范围数据体检与问题清单

**Status:** ready-for-agent

- [ ] 配置入口支持受限规则类型及参数校验，不开放任意脚本或查询；领域字段、阈值和解释来自模板数据。
- [ ] 支持字段组合规范化后的精确重复候选、引用目标缺失、模板声明的字段一致性比较；候选只提示，不自动合并删除。
- [ ] 引用目标无权读取与确认不存在明确区分；多条合法申报不能被直接判定为法律错误。
- [ ] 每次运行固定规则版本；版本升级保留旧问题和运行关联，旧依据不能被静默用于新规则复核。
- [ ] 页面可配置并演示三类问题定位；测试覆盖重复组稳定身份、跨页候选、权限不可判断及规则升级。

## 共同约束

- 父规格为“律师团队数据完善与运营闭环”；本票不改变其范围与身份边界。
- 复用现有模块、领域词汇和 ADR；必要的局部预重构先保持现有行为测试通过，再增加本票能力。
- 按实际涉及内容加载仓库规定的技能；业务数据使用调用者会话，权限落在数据库，不新增业务 CRUD/LIVE 后端代理。
- 交付包含所需持久化、授权、界面或工具入口与行为测试，不以单一层实现作为完成。
