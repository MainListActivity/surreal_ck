# 08 — 数据完善进度与成效指标

**What to build:** 团队看到导入、体检、成员首次登录和复核进度，并可将成效指标纳入授权摘要，运营页面与 MCP 能解释指标口径。

**Blocked by:** 01 — 导入批次持久化与安全重试；06 — 真人派单与复核闭环；07 — 授权摘要共享与运营查询

**Status:** ready-for-agent

- [ ] 进度来自持久批次、体检、派单和成员状态，刷新可恢复，不以单纯页面点击认定业务成功。
- [ ] 实现首次复核耗时、批次失败率及拒绝行比例、固定运行的问题解决率、多人协作和次周更新；严格采用父规格分母与时区定义。
- [ ] 零问题显示不适用、未复核显示未完成、无证据显示未知；结果待核实单列，不适用问题不能冒充复核关闭。
- [ ] 业务更新时间须来自真实持久操作证据；不存在可靠来源时保持未知，不为凑指标扫描客户正文。
- [ ] 客户进度页可预览新增摘要字段并主动提交，独立运营页面和 MCP 同步支持新版本与新鲜度展示。
- [ ] 冻结时钟测试第 7 至第 13 个自然日、时区边界、不同真人、固定分母和缺失证据，保留旧摘要版本兼容。

## 共同约束

- 父规格为“律师团队数据完善与运营闭环”；本票不改变其范围与身份边界。
- 复用现有模块、领域词汇和 ADR；必要的局部预重构先保持现有行为测试通过，再增加本票能力。
- 按实际涉及内容加载仓库规定的技能；业务数据使用调用者会话，权限落在数据库，不新增业务 CRUD/LIVE 后端代理。
- 交付包含所需持久化、授权、界面或工具入口与行为测试，不以单一层实现作为完成。
