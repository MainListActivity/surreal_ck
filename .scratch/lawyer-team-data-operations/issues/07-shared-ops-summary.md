# 07 — 授权摘要共享与运营查询

**What to build:** 管理员预览并共享最小团队启用摘要，独立运营页面和 MCP 可分页读取，管理员撤回后停止展示并清除摘要内容。

**Blocked by:** 无 — 可立即开始

**Status:** done

- [x] 首版只依赖已有成员及工作簿启用信息；采用版本化摘要契约，预留导入和复核指标为未知，不伪造数值。
- [x] 管理员预览共享字段后主动提交；窄动作验证成员、管理员身份、工作区绑定、白名单及大小限制，不接受任意工作区冒领。
- [x] 摘要包含周期、阶段、数量、来源、更新时间和去重身份，不包含文件名、案件名、正文、材料或成员邮箱。
- [x] 独立运营页面与既有 OAuth MCP 复用同一服务，支持读取详情和稳定分页；实时 capability 与 scope 收窄均生效。
- [x] 撤回清除内容并留下最小审计，重复提交幂等；摘要标记团队提供，不用于收费授权或冒充服务端可信全站计量。
- [x] 未知、未完成和失败分开显示；不通过 root 扫描客户台账，不重建运营应用或 MCP 入口。
- [x] 用真实授权边界测试伪造身份、白名单、去重、撤回、撤权与分页，页面和 MCP 可演示相同结果。

## 共同约束

- 父规格为“律师团队数据完善与运营闭环”；本票不改变其范围与身份边界。
- 复用现有模块、领域词汇和 ADR；必要的局部预重构先保持现有行为测试通过，再增加本票能力。
- 按实际涉及内容加载仓库规定的技能；业务数据使用调用者会话，权限落在数据库，不新增业务 CRUD/LIVE 后端代理。
- 交付包含所需持久化、授权、界面或工具入口与行为测试，不以单一层实现作为完成。
