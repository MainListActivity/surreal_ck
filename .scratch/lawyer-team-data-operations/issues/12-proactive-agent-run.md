# 12 — agent 主动运营与断点恢复

**What to build:** 外部 agent 经现有 MCP 完成发现、认领、推进和到期核查，并在中断后继续，运营人员可看到运行进度、失败和人工接管入口。

**Blocked by:** 10 — 运营建议审阅与行动记录；11 — 自动运营授权与暂停控制

**Status:** done

- [x] 交付可运行的外部 agent 驱动示例或适配，使用真实 MCP 工具链，不以页面自动点击替代；不新增常驻调度平台。
- [x] 持久运行身份、摘要游标、已处理动作、到期检查项和检查点；恢复先核实不确定结果，成功副作用不重放。
- [x] 按配置周期或变更游标发现机会，依权限自动维护内部事项或提交建议，后续工具状态确认结果；没有新证据不能宣称客户问题已解决。
- [x] 重试次数、单轮动作数和时间预算有明确配置，达到上限转待人工处理；陈旧摘要显示新鲜度限制，不冒充实时监测。
- [x] 执行服从租约、实时授权和暂停，人工接管或来源撤回后停止对应动作，保留最小运行历史。
- [x] 说明运行宿主、频率、预算和凭证刷新需求；客户端退出后不得显示仍在主动运行。本票不自动创建生产定时作业。
- [x] 固定模型替身配合真实服务验证发现至结果核查，中断恢复、重复轮次、租约过期、暂停、撤权及重试耗尽均有可见结果。

## 共同约束

- 父规格为“律师团队数据完善与运营闭环”；本票不改变其范围与身份边界。
- 复用现有模块、领域词汇和 ADR；必要的局部预重构先保持现有行为测试通过，再增加本票能力。
- 按实际涉及内容加载仓库规定的技能；业务数据使用调用者会话，权限落在数据库，不新增业务 CRUD/LIVE 后端代理。
- 交付包含所需持久化、授权、界面或工具入口与行为测试，不以单一层实现作为完成。
