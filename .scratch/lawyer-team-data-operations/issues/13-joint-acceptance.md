# 13 — 律师团队与主动运营联合验收

**What to build:** 以隔离工作区和脱敏台账演示客户数据完善与 agent 主动运营的完整过程，给出可重复验收证据和剩余限制。

**Blocked by:** 02 — 导入批次安全撤销；04 — 模板规则与跨记录检查；08 — 数据完善进度与成效指标；12 — agent 主动运营与断点恢复

**Status:** ready-for-agent

- [ ] 使用至少 501 条记录及多工作表夹具，覆盖缺失、格式错误、合法重复、疑似重复、引用异常、零问题台账及部分导入失败。
- [ ] 真实管理员与普通成员完成导入、失败行恢复、体检、修正、派单、另一真人复核与成效展示；并演示安全撤销与撤销阻碍。
- [ ] 管理员共享摘要后，运营页面及 OAuth MCP 看到相同授权状态；agent 发现机会、认领、推进建议、核查结果，人工可接管。
- [ ] 验证跨工作区拒绝、撤回摘要、scope 收窄、实时撤权、并发更新、中断恢复和暂停；不以手工万能 token 绕过真实认证。
- [ ] 校验所有新增持久结构可经正常迁移部署，既有导入、模板、配额运营与 MCP 内容工具不退化。
- [ ] 各前置票自行完成行为测试，本票只补跨模块真实串联和回归证据；执行适用的 pnpm 检查，记录环境、结果和限制。
- [ ] 不在生产真实台账做测试性写入，不自动发外部消息、不部署生产或创建定时作业；输出独立可复现演示步骤。

## 共同约束

- 父规格为“律师团队数据完善与运营闭环”；本票不改变其范围与身份边界。
- 复用现有模块、领域词汇和 ADR；必要的局部预重构先保持现有行为测试通过，再增加本票能力。
- 按实际涉及内容加载仓库规定的技能；业务数据使用调用者会话，权限落在数据库，不新增业务 CRUD/LIVE 后端代理。
- 交付包含所需持久化、授权、界面或工具入口与行为测试，不以单一层实现作为完成。
