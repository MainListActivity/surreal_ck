# 03 — 全范围数据体检与问题清单

**What to build:** 律师从已有工作簿启动必填与格式体检，看到完整范围的进度、问题依据和记录定位，并可取消或重新检查。

**Blocked by:** 无 — 可立即开始

**Status:** ready-for-agent

- [ ] 经数据表运行时提供全范围读取和体检编排，不以默认 500 条窗口冒充全量；至少 501 条夹具末尾问题可被发现。
- [ ] 持久体检范围、规则版本、开始结束时间、问题稳定身份及依据指纹；提供处理中、完成、部分完成、失败和取消状态。
- [ ] 首批必填和格式规则复用字段约束；无法读取、字段不存在或执行失败不能显示为无问题。
- [ ] 问题清单显示类别、解释、规则、记录及字段定位；仅完整成功扫描才可显示范围内未发现问题。
- [ ] 同版本重扫合并问题并保留处理历史；跨页期间数据变化标记待重检，不宣称不存在的快照保证。
- [ ] 切换工作区后清理旧页面状态和订阅；业务数据与运行结果保存在各自工作区，普通成员和跨工作区权限由数据库验证。
- [ ] 使用已有公开运行时接口测试扫描、取消、恢复展示、重扫和并发变化；新增概念同步领域词汇。

## 共同约束

- 父规格为“律师团队数据完善与运营闭环”；本票不改变其范围与身份边界。
- 复用现有模块、领域词汇和 ADR；必要的局部预重构先保持现有行为测试通过，再增加本票能力。
- 按实际涉及内容加载仓库规定的技能；业务数据使用调用者会话，权限落在数据库，不新增业务 CRUD/LIVE 后端代理。
- 交付包含所需持久化、授权、界面或工具入口与行为测试，不以单一层实现作为完成。
