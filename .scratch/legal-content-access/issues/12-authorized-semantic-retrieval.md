# 12 — 授权范围内的语义类案检索

**What to build:** 成员以自然语言寻找相关法条和类案，平台在其有权访问的内容内结合关键词和语义召回，提高相关性，并能解释采用的法律依据。

**Repository:** surreal_ck

## Acceptance criteria

- [ ] 在既有授权检索接口内部引入独立的平台与私有资料 retrieval adapter，保留调用者会话与许可约束，接口不接受模型指定授权集合。
- [ ] HNSW 候选必须在数据库权限允许范围内召回和返回；跨集合过滤导致召回不足时使用经验证的授权分区或数据库内筛选，不以取回未授权全文再过滤换取召回率。
- [ ] 关键词、语义、法源/裁判层级、法域、程序、争点、效力和质量信号进入可版本化排序；不跨索引直接比较原始向量距离，也不把越新越相关作为通则。
- [ ] 按稳定内容身份、来源及哈希处理重复文书，保留可引用的来源差异；结果仍携带精确版本并经过证据注册与引用校验。
- [ ] 向量不可用时在同一授权范围内降级到关键词/结构化检索并说明能力变化；普通语义检索不逐次扣 AI 研究额度。
- [ ] 缓存标识包含 embedding/ranking 与 release 版本；旧索引、重建和滚动更新不能复活已撤回内容或串用别的工作区候选。
- [ ] 在固定且可合法使用的法律检索集上报告召回率、排序质量、延迟及授权泄露检查，与关键词基线比较；参数和阈值由测量记录决定。
- [ ] 浏览器展示相关结果及有限排序解释，检验低召回、索引故障、授权集合变化、无 AI 使用许可来源和跨工作区私有资料的负例。
