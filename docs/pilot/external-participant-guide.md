# 外部参会人免安装 3 步入会指南

手机和电脑都可以参加，无需安装应用或注册账号。请保管好主持人发给你的链接和访问码。

## 1. 在浏览器打开专属链接

在微信里点开链接后，点右上角「⋯」，选择「在浏览器打开」。如果菜单里只有「复制链接」，复制后粘贴到手机自带浏览器或 Chrome 中打开。电脑可用 Chrome、Edge 或 Safari。请使用主持人直接发给你的原链接。

## 2. 核验身份，确认存证告知

- 参加**正式会议**时，填访问码，按页面提示填写主持人告知的名册校对信息，点「核验并参会」。页面会显示名册里的姓名，请核对。阅读录制告知并勾选「我已知情并确认进入录制会议」。如进入等候室，请保持页面打开，等待主持人准入。同一时间请只用一台设备参会。
- 参加**日常访客会议**时，填写展示名称。如主持人设置了访问码，一并填写。点「进入等候室」，等待主持人放行。姓名不符或核验未通过时，请联系主持人核对。

## 3. 听讲、发言和表决

- 入会后可先听讲。如果听不到声音，点「开启声音」（如有提示），再检查手机或电脑的音量。正式会议想发言时，点「举手申请发言」。主持人允许后，点「打开麦克风」，按浏览器提示授权。发言结束后关闭麦克风。
- 正式会议如有表决，在「会议表决」选议题，点「填写表决」，选择选项。需要提出异议时，在「书面异议或意见」中填写，截止前点「确认提交」。看到「已提交」后可下载个人回执。允许改票时，截止前可点「修改表决」。
- 手机网络卡顿时，如有「纯音频省流模式」，点它可暂停接收画面并继续听讲。接完电话或切换网络后，回到原浏览器页面等候重连。若页面出现「重新连接」，点一下即可。仍无法进入时，请联系主持人。
