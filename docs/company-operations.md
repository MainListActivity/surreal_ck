# 公司任务与交接入口

公司级任务在私有仓库 [surreal-ck-operations](https://github.com/MainListActivity/surreal-ck-operations) 管理。岗位分工、个人队列、任务状态、验收和交接规则以该仓库 README 及 docs 为准。

用户是唯一真人负责人；其余岗位为 AI agent。同岗位允许多位员工，稳定员工编号与实际会话分别登记，按岗位队列领取任务。共用 GitHub assignee 不能区分员工；领取、提交、独立验收遵循运营仓库 `agents/PROTOCOL.md` 和 `scripts/queue.py`。真实律师用户和外援顾问问题统一交 owner。

领取经营、客户交付、跨岗位验收或发布交接任务时，先打开公司工作台，确认当前岗位、实际领取员工、输入、验收人、授权和后续任务。公司任务使用 GitHub Issues；本产品仓库的技术 PRD 和实现工单继续按 [issue-tracker.md](agents/issue-tracker.md) 保存在 `.scratch/`。

公司阶段任务链接具体技术规格与 PR，不批量复制历史工单。技术工单完成不代表客户验收、发布授权或商业结果完成；这些决定在私有公司任务中记录。

当前产品仓库公开。客户资料、报价、合同、公司经营报告及私有任务内容留在私有工作台或受控资料存储，公开 PR 仅包含可公开的技术内容。本文件不授予客户联系、签约、付款或生产发布权限。
