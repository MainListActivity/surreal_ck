# ADR：债委会与法院的只读聚合入口

- **Status**：Proposed，待经理批准。未批准前不实施、不启用入口。
- **Date**：2026-11-20
- **关联决策**：[前端默认直连](./frontend-direct-connect.md)、[债权人令牌提交窄入口](./creditor-token-submit.md)

## 决策

提议在 Hono 增设第二个窄例外：债委会和法院只能凭独立查看链接，通过固定响应读取本案已发布的统计快照。不能查询原始记录、指定筛选条件、订阅 LIVE，不能获得 IdP 账号、workspace scope 或数据库凭证。管理人的日常业务操作仍直连。相较于把外部主体加入 workspace，此方案不授予实体表权限；相较于通用统计 API，此方案限制了可做差分的查询范围。

## 响应白名单

| 字段 | 债委会 | 法院 | 口径 |
| --- | --- | --- | --- |
| `generated_at`、`metric_version` | 可见 | 可见 | 快照时间、口径版本 |
| `submitted_count`、`reviewed_count`、`stage_counts` | 可见 | 可见 | 每债权人至多一份首次有效申报；已发布过结论才计为已审查 |
| `declared_total`、`confirmed_total`、`claim_type_distribution` | 可见 | 可见 | 已提交金额、最新已发布确认金额；债权类型按同一固定分类 |
| `weekly_progress` | 可见 | 可见 | 固定案件时区和自然周，不开放日期区间参数 |
| `open_objection_count`、`oldest_objection_wait_days_band` | 不可见 | 可见 | 按仍待处理且去重后的债权人计数；等待天数用区间，不返回个人对应的精确时长 |

不返回名称、识别码、附件、内部笔记、个人时间、原始记录 ID 或单笔金额。角色从服务端令牌记录确定，不能由请求指定；共同字段在同一快照中完全一致。空值表示未发布或因保护规则隐藏；不得把隐藏项渲染为零。

## 小分组与跨快照防推断

1. 分组按参与计算的去重债权人数判断。人数少于 3 的分组并入「其他」；若「其他」仍少于 3，则隐藏整项分布或合并更多分组，不同时发布能还原隐藏值的总量和其余分项。
2. 金额和最长等待区间按各指标的实际贡献人数另做阈值判断。仅因某个其他字段有足够人数，不得公布当前指标的小样本。
3. 只提供固定口径和预生成快照。发出新快照前与已发布口径对比；若按总量、分组或跨周变化能隔离不足 3 人的贡献，则延迟发布相应值、合并分组或隐藏相关字段。不能把切换角色、补发令牌或轮询视为新的发布周期；所有访问者共用同一已发布快照。验收必须覆盖小案件、稀疏异议和逐个新增/移动记录。

## 查看链接、过期与审计

- 每位查看者单独签发。数据库只保存查看令牌和访问码的校验材料、角色、到期时间、状态、最近访问和次数；访问者标签仅管理人可见。不能使用债权人申报令牌打开看板。
- 访问码独立转发。失败响应不区分错误访问码、令牌不存在、过期或作废；按令牌和来源限速，复用债权人入口的限速常量。成功会话最长 2 小时且不超过令牌期限；续用请求重查状态，作废后下一次访问即失败。
- 审计仅记录签发、作废、成功访问的时间、对象 ID 和操作者或查看角色；不记录明文、访问码、原始查询或聚合正文。外部响应不可缓存。归档保留期由案件政策确认前不作变更。

## 批准与验收

经理批准后记录批准依据，再实施并更新两份关联 ADR 的例外清单。先在真实 fork 验证两种角色的白名单、期限和作废，再用真实页面验证统计发布；至少覆盖「其他」不足 3 人、只新增 1 人、两角色字段相减、逐周变化和粘贴跨案链接。
