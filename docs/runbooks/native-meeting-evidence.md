# 原生会议候选验收证据模板

每个环境各填一份。结果用「通过 / 失败 / 未测（原因）」。运行前填基线，运行中只保留脱敏证据；不要附会议号、邮箱/主体 ID、IP、原始 SDP、登录 URL、token、密码或 TURN 凭据。不要录用户身份登录步骤。

| 条目 | 记录 |
| --- | --- |
| 执行日期与责任人 | |
| 代码 / 企业包 / 默认预览包 | 完整 SHA；企业包与预览包哈希及构建回执 |
| 数据库 | fork 版本和制品哈希；会议迁移名和 SHA-256；实际模板末版本；授权/迁移回执 |
| 场景 | 本地 fork / 同机 / 跨网直连 / 授权 TURN；设备及网络代号与 OS；是否跨 NAT |
| 真人身份 | A / B / C；实际角色、三个独立进程/浏览器/客户端目录已核对 |
| TURN | 关闭 / 已批准；授权记录及窗口（不含端点或凭据）；回收结果 |

## 选中 ICE 路径与 RTP

每个阶段复制下表（至少：初次三人直连、C 离开与重入、AC 直连失败无 TURN、AC 授权回退）。每格对每端填写 `direct / relay / unknown`、同一秒表窗口内的 RTP 发/收增量及比较用的非敏感轮次代号。未建立的边写明失败或离开，未观察到的指标写「未测」。不要把候选类型、SDP 或 IP 当作字段保存。

## 用例

| 用例 | 期望及需记录的事实 | 结果 / 证据 |
| --- | --- | --- |
| 真账号、同版 schema | A 普通成员；B/C 为不同真人；实际 schema 与候选一致；旧版 fail closed | |
| 创建并邀请、两种加入 | A 建会并邀请 B/C；B 从邀请加入，C 通过会议号加入；每端两条边 | |
| 默认关闭与真实音视频 | 关闭设备能入会；每端实际收听并看到另外两端，来源可区分 | |
| 显式共享与停止 | 选窗口；B/C 同时可见；停止后 B/C 各自确认画面消失 | |
| 离开、重入与迟到 SDP | C 变更只影响 AC/BC；AB 媒体连续、轮次不变；旧实例与旧 SDP 不复活 | |
| 并发占位与满员 | 部分账号用本地 fork 独立 fixture 补齐到容量上限；同账号幂等且名额不超卖；满员错误可辨认 | |
| 普通 RECORD 权限与撤权 | 未邀请与无效会议号同语义；跨 workspace、非边端点、已撤权不得读名单/SDP 或加入；两条合法边可并发建立 | |
| 掉线、租约与硬过期 | 主持人掉线不立即解散，租约到期只删成员；无人/硬过期自然结束；过期信令不恢复 | |
| 结束与隐私 | 非主持人不能结束；主持人结束/切工作区/退出/注销时本机发送先停；无法确认停止时保留隐私告警 | |
| 单边直连失败、无授权 | AC 明示失败且不使用公共中继；AB/BC 仍直连，另测一端无凭据 | |
| 单边授权回退 | 仅 AC 直连失败后重新协商 relay；AB/BC 保持直连、轮次不变，RTP 持续；临时分配已回收 | |
| 三端 UDP 压测 | 记录测试命令、持续时间、退出码，三边可用且任务/资源回收 | |
| 回归 | 企业 OIDC 双人聊天仍可用；同 SHA 默认预览会议不可用 | |

**结论与未测条件：** 单列同机拓扑、真实媒体、跨 NAT、公网/生产 TURN；附脱敏证据链接，不把本地 fixture、账号列表或任一单边结果当作三账号通过。
