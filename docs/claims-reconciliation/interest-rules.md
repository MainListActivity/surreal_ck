# 11.1 债权对账 · 利息规则（v1）

- **Status**: Accepted（经理锁定，设计定稿 `7f671391`）
- **Rule version id**: `interest-rules/v1`
- **Date**: 2026-10-03
- **Companion**: [`data-model.md`](./data-model.md)

## 原则

1. **不用 AI 给出利息数字**。计算必须是确定性函数；AI 最多辅助阅读合同条款提案，数字以本规则引擎为准并经管理人确认。
2. **v1 只做单利**（`interest_method = simple`）。复利、罚息滚入本金等留待后续版本。
3. **允许按约定日期分段换利率**。每一段有自己的年利率与半开日区间。
4. **没有约定的违约金不算**。申报里违约金为空或债权人未主张约定依据时，系统重算总额不含违约金。
5. **每次计算保存 `rule_version` 与完整输入/分段快照**。历史结果不因以后改规则或改代码而被改写；新规则使用新版本 id 另算。

## 日计数

- 使用**日历日**。
- 区间为**半开区间** `[起, 止)`：含起始日，不含终止日。
- 天数 = `终止日 − 起始日`（日期差的整天数）。
- **闰日按日历计入分子**（例如 2024-02-29 落在区间内则计 1 天）。
- **年利率日因子分母固定为 365**（v1 锁定，便于手算对拍；不因闰年改为 366）。

$$
\text{单利利息} = \text{本金} \times \text{年利率} \times \frac{\text{区间天数}}{365}
$$

金额计算使用十进制，**四舍五入到分**（两位小数）；分段先各自舍入到分，再求和得到合计（避免先求和再舍入导致与逐段展示不一致）。

## 分段

输入：

- 本金 `P`（全程同一基数；v1 不分段改变本金）
- 有序分段列表：每段 `{ start, end, annual_rate }`，满足：
  - 第一段 `start` = 申报计息起始日
  - 最后一段 `end` = 申报计息终止日
  - 相邻段首尾相接：`segments[i].end == segments[i+1].start`
  - 每段 `end > start`，`annual_rate ≥ 0`

对每段 `i`：

$$
d_i = \mathrm{days}(start_i, end_i),\quad
I_i = \mathrm{round}(P \times r_i \times d_i / 365,\ 2)
$$

合计利息 \( I = \sum I_i \)。

不计息：允许零段或显式 `annual_rate = 0` 覆盖全区间，合计为 `0.00`。

## 手算例题（对拍基准）

**输入**

| 项 | 值 |
| --- | --- |
| 本金 \(P\) | `100000.00` |
| 计息起始 | `2024-01-01` |
| 计息终止 | `2025-01-01` |
| 分段 1 | `[2024-01-01, 2024-07-01)`，年利率 `6%` = `0.06` |
| 分段 2 | `[2024-07-01, 2025-01-01)`，年利率 `8%` = `0.08` |
| 规则版本 | `interest-rules/v1` |
| 违约金 | 无约定 → 不算 |

**分段 1**

- 天数：`2024-07-01 − 2024-01-01` = **182**（2024 为闰年，2 月 29 日计入）
- 利息：`100000 × 0.06 × 182 / 365` = `2991.7808…` → **`2991.78`**

**分段 2**

- 天数：`2025-01-01 − 2024-07-01` = **184**
- 利息：`100000 × 0.08 × 184 / 365` = `4032.8767…` → **`4032.88`**

**合计**

| 段 | 起 | 止（不含） | 天数 | 基数 | 年利率 | 利息 |
| --- | --- | --- | ---: | ---: | ---: | ---: |
| 1 | 2024-01-01 | 2024-07-01 | 182 | 100000.00 | 0.06 | 2991.78 |
| 2 | 2024-07-01 | 2025-01-01 | 184 | 100000.00 | 0.08 | 4032.88 |
| **合计** | | | **366** | | | **7024.66** |

实现单测与律师手算对拍时，必须以本表金额为准。若未来修订规则，新版本另给例题，本例题仍用于校验 `interest-rules/v1` 引擎。

## 与对账视图的关系

对账并排展示「债权人申报 / 企业账面 / 系统按合同重算」。系统重算列读取最新一次（或管理人指定的一次）`interest_calculation` 快照；**利息差**类差异比较账面利息与该快照合计（以及申报主张是否一致）。具体 UI 在对账交付实现。

## 本期不做

- 复利、复利频率、罚息滚入本金
- 360 天商业计息制
- AI 直接输出利息数字
- 自动改写历史快照
