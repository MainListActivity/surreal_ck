## 名册模板 `creditor-roster.xlsx`

工作表名：`名册`。

| 列标题（第 1 行） | 对应字段 | 填写说明 |
| --- | --- | --- |
| 主体类型 | `subject_type` | 填 `企业` 或 `个人`（导入映射到 `enterprise` / `person`） |
| 名称 | `name` | 企业全称或个人姓名 |
| 唯一识别码 | `identity_code` | 非空；本文件内唯一；**不做**证件校验算法 |
| 对接联系人 | `contact_name` | **企业必填**；缺则拒绝该行并返回行号 |
| 联系方式 | `contact_channel` | 手机或邮箱等 |

示例行（已写入模板，可删）：

| 主体类型 | 名称 | 唯一识别码 | 对接联系人 | 联系方式 |
| --- | --- | --- | --- | --- |
| 企业 | 示例·华辰建设有限公司 | 91320100MA01HC001X | 张明 | 13800001001 |
| 个人 | 示例·李某 | 320102198805120018 | 李某 | 13800001003 |

## 账面模板 `enterprise-ledger.xlsx`

工作表名：`账面`。

| 列标题（第 1 行） | 对应字段 | 填写说明 |
| --- | --- | --- |
| 唯一识别码 | `identity_code` | 必须已在名册中；否则拒绝并返回行号 |
| 本金 | `principal` | 数字，≥ 0 |
| 账面利息 | `book_interest` | 数字，≥ 0 |
| 合同引用 | `contract_ref` | 可空 |
| 备注 | `note` | 可空 |

示例行（已写入模板，可删）：

| 唯一识别码 | 本金 | 账面利息 | 合同引用 | 备注 |
| --- | --- | --- | --- | --- |
| 91320100MA01HC001X | 100000 | 5000 | 示例合同-2023-001 | |

## 导入顺序与错误语义

1. 先导名册，再导账面。
2. 名册：企业缺对接联系人 → 拒绝该行 + 行号；识别码空或重复 → 拒绝 + 行号。
3. 账面：识别码不在名册 → 拒绝 + 行号；金额非数字或负 → 拒绝 + 行号。
4. 成功行提交；失败行不写入。允许整文件「部分成功」或「遇错全停」由导入实现选定，但**错误必须带行号**。
5. 未知债权人不能通过导入或门户自助出现在名册外；须管理人补名册后再发令牌链接。
