## 交互与实现约束

1. **身份与边界**：沿用已有企业身份、工作区、成员体系；新私聊/群聊必须独立校验会话成员权限，不把工作区公共活动流当私聊。
2. **聊天**：至少区分发送中、已发送、发送失败可重试、已读。断线显示离线/重连状态；补齐历史后更新未读，避免重连重复消息。附图内文件、置顶、在线状态、已读是体验提案，是否纳入 MVP 需评估，并非已有功能声明。
3. **加入前**：首次使用显示摄像头/麦克风权限与设备预检；拒绝权限时可关闭摄像头或以听众模式进入，不循环弹窗。
4. **会议**：自己的共享生效后，应出现持续可见的「正在共享」与「停止共享」，不能只靠金色图标表达。第二张为观看他人共享，正式实现应明确自身是否正在共享，不直接照搬按钮高亮。
5. **共享**：开始按钮在未选择源或权限不足时禁用；窗口关闭/来源失效立即停止轨道并提示。取消、Esc、关闭仅退出选择器，不退出会议。平台要求时使用系统原生选择器，不用自绘界面代替系统授权。
6. **隐私**：窗口共享不等于绝对无泄漏保证，系统对话框、窗口内通知或平台行为仍需验证。第一张气泡的「其他内容不会展示」仅为示例聊天文案，正式产品承诺改为「默认仅共享所选窗口，请确认预览内容」。
7. **音频**：系统音频依操作系统及采集能力开放；不支持时给出说明或隐藏，不显示可用假象。
8. **离开**：参与者离开自己的会议；主持人若支持结束全体会议，必须单独明确操作。重连中保留会议信息，禁止误报网络良好。
9. **键盘与可访问性**：系统字体，正文建议 14–16px；图标提供可访问名称；焦点可见；弹窗焦点约束与返回；状态不只依赖颜色。金色按钮使用深色文字，必要文字至少满足 WCAG AA 对比度。

## 视觉规格建议

- 暖白画布 `#FAF9F6`，主文字/会议舞台 `#161513`，品牌金 `#F5C542`。
- 边框采用低对比中性灰，圆角 8–10px，8px 间距基线。
- 左侧导航约 64–72px，会话栏约 280–320px，其余空间优先给内容；不是数据控制台。
- macOS 预览使用交通灯，Windows/Linux 应使用各自窗口规范，不复制 macOS 装饰。
- 图像内的品牌图标属于生成近似，仅供构图预览。正式实现复用 `Logo.svelte` 中准确的猫背影与金色数据墙几何，或由其导出原生资产，**不替换现有品牌资产**。
- 浅色共享选择器与深色共享舞台是两种场景提案；最终会议主题应统一，保留系统原生弹窗的可识别性。
