# 协作原生客户端设计基础

目标：桌面 Linux/macOS/Windows 与 Android 原生视图，不使用 WebView。先做真实可用状态，再接聊天和传输，不用假成功状态。

- 颜色：暖白画布 `#FAF9F6`、主文字/会议舞台 `#161513`、品牌金 `#F5C542`，并通过 NSH theme 的 background/foreground/primary/input/muted_foreground 语义角色支持明暗主题。
- 控件：src/ui 管理按钮、输入框、导航项、筛选条和消息气泡；Android触摸尺寸至少48dp，桌面首版沿用宽松尺寸。
- 字号：分区标题约20–22、正文14–16；间距以 8px 为基线，圆角 8–10px（theme.radius）。
- 布局：左侧图标导航约 64–72px，消息页会话栏约 280–320px，其余空间给内容。这是协同客户端，不是数据控制台。
- 窗口：标题为「吉吉 · 团队协同」。Linux/Windows 使用系统窗口装饰，不绘制伪造的 macOS 交通灯。品牌标志复用现有 Logo 几何，不用设计稿里的近似图标。
- 动效清单：按钮hover/pressed透明度反馈；连接状态更新只反映真实传输事件；尊重减少动态效果，不添加无意义等待动画。
- 未完检查：明暗主题截图、平台键盘焦点、移动端安全区和返回行为需在实际窗口/模拟器验证。
- 数据：未接传输时保持离线，草稿明确标记仅当前会话、未发送、不持久化。不生成示例联系人、假消息、假在线人数或假会议。

## 产品壳层（H-03）

- 消息页：窄图标导航（消息、会议、成员，底部设置）、会话栏（标题「消息」、搜索、全部/未读/群聊）与主区（会话头、气泡记录、底部「输入消息，Enter 发送」）。企业登录未配置时，在列表空状态中如实说明「此构建未接入企业登录，不会模拟登录」。
- 会议页：深色内容优先舞台、右侧参会人栏、底部坞（麦克风、摄像头、共享屏幕、参会人、聊天、离开会议）。尚未接入企业会话时显示「尚未接入企业会话，无法开始真实会议」，坞控件禁用；不渲染示例人像，也不显示「正在共享」。
- 共享选择器：默认选中「窗口」，提示共享整个屏幕可能暴露通知和其他窗口；「开始共享」在没有真实源和进行中的会议时保持禁用，空状态为「尚未接入捕获」。取消或 Esc 只关闭选择器。
- 设置页占用完整内容区（标题「设置」），不再复用「消息」会话栏。版本与 GitHub 更新（检查更新与下载分开，预览版不宣称自动升级成功）以及「打开开发者诊断」入口在此页。诊断仍是设置的子页，P2P / STUN/TURN / 指纹 / 媒体与文件调试不出现在消息或会议页。
- 预览构建用紧凑「实验预览版」徽标，完整说明放在设置页。隐私状态与「断开并停止媒体」在顶部栏常驻，不做成通栏状态堆。
- 已送出只表示已交给加密通道；协议无送达/已读回执时不显示已送达或已读。离线发送保持禁用，不假装成功。

## 首屏信息架构（H-02）

- 产品主路径是企业身份、会话与消息；手动 P2P、STUN/TURN、连接指纹和媒体/文件调试在「设置 → 打开开发者诊断」。
- 真实状态：未配置、未登录、加载中、空列表、离线、连接失败、发送中、已送出、发送失败。
