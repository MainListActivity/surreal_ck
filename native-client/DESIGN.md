# 协作原生客户端设计基础

目标：桌面 Linux/macOS/Windows 与 Android 原生视图，不使用 WebView。先做真实可用状态，再接聊天和传输，不用假成功状态。

- 颜色：暖白画布 `#FAF9F6`、主文字/会议舞台 `#161513`、品牌金 `#F5C542`，并通过 NSH theme 的 background/foreground/primary/input/muted_foreground 语义角色支持明暗主题。
- 控件：src/ui 管理按钮、输入框、导航项、筛选条和消息气泡；Android触摸尺寸至少48dp，桌面首版沿用宽松尺寸。
- 字号：分区标题约26–28、正文14–16；间距以 8px 为基线，避免把标题和说明挤成一行。圆角 8–12px（theme.radius）。
- 布局：左侧图标列内容宽度 72px，水平内边距另计（侧栏总宽约 96px），只放线框图标（消息/会议/成员，底部设置），用可访问名称而不是把单字叠在窄标签上。消息页会话栏约 360px，其余空间给内容。这是协同客户端，不是数据控制台。
- 窗口：标题为「吉吉 · 团队协同」。Linux/Windows 使用系统窗口装饰，不绘制伪造的 macOS 交通灯。侧栏品牌标是现有 Logo.svelte 几何（brand.svg），以内禀 256 渲染后再缩到侧栏尺寸，避免发糊的深色小方块。
- 动效清单：按钮hover/pressed透明度反馈；连接状态更新只反映真实传输事件；尊重减少动态效果，不添加无意义等待动画。
- 未完检查：明暗主题截图、平台键盘焦点、移动端安全区和返回行为需在实际窗口/模拟器验证。
- 数据：未接传输时保持离线，草稿明确标记仅当前会话、未发送、不持久化。不生成示例联系人、假消息、假在线人数或假会议。

## 产品壳层（H-03）

- 消息页：窄图标导航（消息、会议、成员，底部设置）、会话栏（标题「消息」、搜索、全部/未读/群聊）与主区（会话头、气泡记录、底部输入条）。未选会话时仍保留会话头，标题为「尚未选择会话。」，不编造成员数或头像。输入条含金色发送控件；附件与表情若未接线则以禁用控件诚实标出「尚未接入」。企业登录未配置时，在列表空状态中如实说明「此构建未接入企业登录，不会模拟登录」。
- 会议页：深色内容铺满工作区，不保留浅色产品侧栏或浅色隐私顶栏切开舞台。顶部工具条含「返回消息」、标题、诚实状态、「断开并停止媒体」、以及禁用的布局/全屏占位。未加入会议时「离开会议」保持禁用，必须用「返回消息」回到产品主路径，不能把用户困在舞台上。右侧参会人栏是一组空槽，不是整块空圆角板，并保留「暂无参会人」说明。底部坞为图标加标签，「离开会议」为红色；麦克风、摄像头、参会人、聊天、离开默认禁用，原因仍是「尚未加入会议，麦克风、摄像头和离开不可用。」。「共享屏幕」仅用于打开选择器预览布局，不会开始共享。尚未接入企业会话时舞台显示「尚未接入企业会话，无法开始真实会议」；不渲染示例人像，也不显示「正在共享」。
- 共享选择器：模态卡片宽约 720px（并设最小宽度，避免被 dialog 外壳压窄），带关闭 X 与「窗口 / 整个屏幕」分段控件，默认选中「窗口」。源区是较高的 2×2 空槽，空状态为「尚未接入捕获」，不放假缩略图。整屏警告以卡片展示既有文案；系统音频是禁用的复选行，并说明尚未接入。「开始共享」在没有真实源和进行中的会议时保持禁用，原因仍是「尚未接入企业会话，无法开始共享」。取消、Esc 或 X 只关闭选择器。
- 设置与成员页使用同一套卡片与字号语言，不再复用「消息」会话栏，主操作是紧凑按钮而不是通栏金色长条。版本与 GitHub 更新（检查更新与下载分开，预览版不宣称自动升级成功）以及「打开开发者诊断」入口在设置页。诊断仍是设置的子页，P2P / STUN/TURN / 指纹 / 媒体与文件调试不出现在消息或会议页。
- 预览构建用紧凑「实验预览版」徽标，完整说明放在设置页。浅色页用紧凑隐私条承载状态与「断开并停止媒体」；会议页将该信息并入深色顶栏，避免浅色横条切开舞台。
- 已送出只表示已交给加密通道；协议无送达/已读回执时不显示已送达或已读。离线发送保持禁用，不假装成功。

## 首屏信息架构（H-02）

- 产品主路径是企业身份、会话与消息；手动 P2P、STUN/TURN、连接指纹和媒体/文件调试在「设置 → 打开开发者诊断」。
- 真实状态：未配置、未登录、加载中、空列表、离线、连接失败、发送中、已送出、发送失败。
